# QuestSystem

Sistema educacional em PHP + MySQL para cadastro de questões, criação de provas, realização de avaliações e acompanhamento de resultados.

## Estrutura técnica

A pasta do projeto continua sendo `projetoyudi` e o banco continua sendo `projetoyudi`.

## Acesso

Professor: dashboard, banco de questões, criação manual, criação com IA, gerenciamento de provas, resultados e gabaritos.

Aluno: dashboard, provas, realização, resultados e histórico.

## Instalação

1. Coloque a pasta `projetoyudi` em `C:\xampp\htdocs\`.
2. Inicie Apache e MySQL no XAMPP.
3. Crie/importa o banco `projetoyudi` usando `banco/banco.sql` apenas quando estiver configurando uma instalação nova.
4. Mantenha sua chave da Gemini em `config/gemini.php`.
5. Acesse `http://localhost/projetoyudi/`.

## Observação

O `config/gemini.php` foi mantido para você preservar a configuração atual da API.
